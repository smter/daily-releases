# Daily（每日日记）

本地优先的 Markdown 日记应用（Android）。以 SAF 磁盘文件为本地真相，与桌面 Obsidian 库共存：应用内编辑 → 导出同步写盘 → 多端镜像，磁盘侧外部改动可检测并逐文件人工抉择。

本仓库仅用于 **正式版 APK 分发**（release 产物），不含源码。

## 安装

1. 到 [Releases](../../releases) 下载最新版 `app-release.apk`；
2. 系统设置 → 应用 → 允许安装未知来源应用；
3. 打开 APK 安装（已用正式签名，可覆盖升级）。

## 功能

- **时间线与日历**：单日五时段时间线、内联月历、日期格三态
- **全文搜索**：FTS5 trigram，中文无分词依赖
- **导出同步**：唯一写盘路径，逐文件 diff + 冲突三选（磁盘版/应用版/跳过）
- **多项目管理**：每个项目独立 SAF 目录树；附件（AVIF）目录独立配置
- **可选坚果云同步**（WebDAV 磁盘镜像）：应用密码认证、双远程路径、首同步调和、手动/打开项目自动同步、冲突三选、附件镜像与降级
- **离线优先**：数据全在本地磁盘，云同步为纯可选能力，未配置时行为与不用云完全一致

## 隐私

数据保存在你选择的本地目录（SAF）。坚果云同步为可选功能，仅在配置账号与应用密码后启用；凭据以系统 Keystore 加密存储。
